# lista-simplificada
Lista de Tarefas/Compras Simplificada

Aplicação web simples para gerenciar listas de tarefas ou compras, 
desenvolvida com HTML, CSS e JavaScript puro.

Funcionalidades

- Adicionar itens à lista
- Remover itens individualmente
- Validação de campos vazios
- Bloqueio de itens duplicados
- Adicionar item com a tecla Enter

Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)

Basta abrir o arquivo `index.html` no navegador. Nenhuma instalação necessária.

Projeto de estudo de JavaScript e DOM.
