Lista de Atividades Acadêmicas

Aplicação web para gerenciar tarefas acadêmicas, desenvolvida com HTML, CSS e JavaScript puro.

Funcionalidades

- Adicionar tarefas com nome, matéria, tipo, integrantes e prazo
- Cor exclusiva por matéria (até 8 matérias simultâneas)
- Bloqueio de tarefas duplicadas
- Validação de todos os campos antes de confirmar
- Remover tarefas individualmente
- Adicionar tarefa com a tecla Enter
- Data formatada automaticamente para dd/mm (dia da semana)

Tecnologias

- HTML5
- CSS3 (Flexbox, position absolute, Google Fonts)
- JavaScript Vanilla
  - Manipulação de DOM (createElement, appendChild, innerHTML)
  - Eventos (addEventListener, keyup, click)
  - Objetos e Arrays
  - Template Literals
  - Objeto nativo Date
  - Closures

Como usar

Abra o arquivo "index.html" no navegador ou acesse solucdev.github.io/lista-simplificada. Nenhuma instalação necessária.
